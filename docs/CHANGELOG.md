# Changelog

## [2026-05-07] Anti-contamination & RAG Relevance Improvements

### Проблема
При анализе контрактов система демонстрировала следующие баги:
1. **RAG-контаминация**: `risk_description` копировался из RAG-контекста, а не из текста сегмента
2. **False positives**: Безопасные пункты (напр. "оплата за выполненную работу") помечались как рискованные
3. **safe_redaction**: Иногда начинался с опасной формулировки
4. **Пропуск рисков**: Сегменты о подсудности не обнаруживались

### Изменения

#### RAG (rag.py)
- **SCORE_THRESHOLD**: повышен с `0.55` до `0.75` для снижения false positives от нерелевантных норм

#### Промпты (analyzer.py)
- Добавлено явное правило **АНТИ-КОНТАМИНАЦИЯ** в SYSTEM_PROMPT_COMPACT и SYSTEM_PROMPT_FULL
- Запрещено копировать `risk_description` из RAG, если риск не присутствует в тексте сегмента
- Добавлены примеры ошибок в промпт для clarity
- Расширен список рисков: добавлены "подсудность", "претензионный порядок"

#### Классификатор (analyzer.py `_classify_risk`)
- Расширен список признаков риска: добавлены подсудность, юрисдикция, претензионный порядок

#### Пост-обработка (analyzer.py)
- **Новый метод `_validate_risk_relevance`**: проверяет релевантность риска тексту сегмента
  - Отклоняет риски для сегментов с safe patterns
  - Отклоняет риски если сегмент не содержит ключевых слов риска
- **Улучшен `_validate_safe_redaction`**: проверяет что safe_redaction не начинается с опасной фразы
- **SAFE_PATTERNS**: список безопасных формулировок которые не должны помечаться как рискованные
- **DANGEROUS_PHRASES**: список опасных фраз которые не должны появляться в начале safe_redaction
